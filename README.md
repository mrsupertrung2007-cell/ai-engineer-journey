# AI Engineer Journey

## Giới thiệu
Mình là Trung, hiện đang là sinh viên tại Trường Đại học Giao thông Vận tải (UTC). Đây là kho lưu trữ ghi lại toàn bộ quá trình tự học, rèn luyện kỹ năng lập trình Python và thực hành xây dựng các ứng dụng AI thực tế của mình.

## Mục tiêu
Mình theo đuổi lộ trình AI Engineer vì muốn trực tiếp ứng dụng sức mạnh của các mô hình ngôn ngữ lớn (LLMs) vào giải quyết các bài toán thực tiễn. Mục tiêu của mình là nắm vững kiến trúc RAG, hệ thống AI Agents và hoàn thiện các dự án thực chiến để ứng tuyển vị trí AI Engineer Intern / Fresher.

## Lộ trình
* **Giai đoạn 1 (Tuần 1 - 6):** Nền tảng lập trình Python, xử lý dữ liệu JSON, quản lý mã nguồn với Git và tích hợp Model APIs (Gemini, OpenAI, Ollama).
* **Giai đoạn 2 (Tuần 7 - 12):** Kỹ thuật Prompt Engineering nâng cao, Structured Outputs, Function Calling và bảo mật AI.
* **Giai đoạn 3 (Tuần 13 - 20):** Làm việc với Vector Databases, Embeddings và xây dựng hệ thống tìm kiếm, hỏi đáp trên tài liệu nội bộ (RAG).
* **Giai đoạn 4 (Tuần 21 - 28):** Phát triển hệ thống Multi-Agent (LangChain, LangGraph), đánh giá chất lượng mô hình (Evaluation/LLMOps) và triển khai sản phẩm hoàn chỉnh.
